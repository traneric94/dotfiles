# Hotkeys

Hand-maintained index. Each config stays the source of truth; this file is the
one place to look. When you change a key, update the matching section here in
the same commit. Every section says where its keys are defined.

Leader (nvim, vim) is `Space`. tmux prefix is `C-a`. herdr prefix is `ctrl+b`.

## Cross-tool chain: Ghostty -> tmux

Cmd shortcuts in Ghostty send the tmux prefix plus a key, so macOS-style chords
drive tmux. Defined in `config/ghostty/config`; targets defined in `tmux.conf`.

| Chord | Sends | tmux action |
|---|---|---|
| Cmd+T | `C-a c` | New window (current path) |
| Cmd+D | `C-a v` | Split side by side |
| Cmd+Shift+D | `C-a h` | Split stacked |
| Cmd+Shift+[ | `C-a p` | Previous window |
| Cmd+Shift+] | `C-a n` | Next window |
| Cmd+1 to Cmd+9 | `C-a 1` to `C-a 9` | Go to window N |

Ghostty also dumps terminal output to a temp file and pastes the path (pair with
the `sb` zsh alias to open the latest dump in nvim):

| Chord | Action |
|---|---|
| Cmd+Shift+J | Dump scrollback |
| Cmd+Shift+S | Dump screen |
| Cmd+Shift+U | Dump selection |

## tmux

Source: `tmux.conf`, `config/tmux/utility.conf`. Prefix `C-a` (`C-b` unbound).
Press the prefix first for rows marked "prefix".

### Pane navigation (no prefix)
Vim-aware: sends the key through when the pane runs vim or nvim.

| Key | Action |
|---|---|
| C-h / C-j / C-k / C-l | Select pane left / down / up / right |
| Alt+arrows | Select pane (backup navigation) |
| Shift+Left / Shift+Right | Previous / next window |

### Splits, windows, config (prefix)

| Key | Action |
|---|---|
| prefix v | Split side by side (current path) |
| prefix h | Split stacked (current path) |
| prefix % / prefix " | Split side by side / stacked (current path) |
| prefix c | New window (current path) |
| prefix r | Reload `~/.tmux.conf` |
| prefix C-h/j/k/l (repeatable) | Resize pane left / down / up / right |

### Popups (prefix, `config/tmux/utility.conf`)

| Key | Action |
|---|---|
| prefix s | Session switcher (fzf with preview) |
| prefix g (repeatable) | lazygit in current path |
| prefix e | Notes inbox (`~/notes/inbox.md` in nvim) |

### Copy mode (vi keys)

| Key | Action |
|---|---|
| C-h/j/k/l | Select pane |
| v | Begin selection |
| y / Enter | Copy and exit |

### Plugins (defaults, not set in this repo)
Unverified: tmux-resurrect uses prefix C-s (save) and C-r (restore), noted in
`utility.conf`. tmux-sidebar and tmux-urlview use their own defaults; check
`prefix + I` / the plugin READMEs if you need them.

## Neovim

Source: `config/nvim/lua/config/keymaps.lua` (LSP keys in
`config/nvim/lua/config/plugins/lsp.lua`, REPL in `plugins/comment-repl.lua`,
group labels in `plugins/which-key.lua`). Leader is `Space`.

### Basics

| Key | Action |
|---|---|
| kj (insert) | Escape |
| `<leader>w` / `<leader>W` | Save file / save all |
| `<leader>q` / `<leader>Q` | Quit window / quit Neovim |
| `<leader>sc` | Clear search highlight |
| `<leader>T` | Terminal buffer |
| `<leader>ve` | Edit nvim config |
| `<leader>r` | Reload nvim config |
| `<leader>tc` | Toggle completion |

### Option toggles (vim-unimpaired style)

| Key | Toggles |
|---|---|
| yow / yos / yol | wrap / spell / list |
| yon / yor / yoc | number / relativenumber / cursorline |
| yoh | hlsearch |

### Clipboard
`<leader>y` yank and `<leader>p` paste use the system clipboard. In visual
mode, `p` pastes over the selection without overwriting the register.

### File explorer and search

| `<leader>fw` | Grep word under cursor (project root) |
| `<leader>fr` | Frecency files |
| `<leader>fb` / `<leader>fo` | Buffers / recent files |
| `<leader>fs` / `<leader>fc` | Git status / git commits |

| `<leader>/` | Search in buffer |

location list, `<leader>qL` close location list. `]q` / `[q` are nvim built-ins.
